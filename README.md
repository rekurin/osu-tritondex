# TritonDex

A UC San Diego-themed osu! player viewer with a static, GitHub Pages-compatible frontend. The workflow runs daily to refresh rankings and top plays. Standard is the default leaderboard, with additional Mania, Taiko, and Catch tabs. Each leaderboard sorts synced entries by PP from highest to lowest. Every roster member is checked in all four game modes, so multi-mode players can appear on every leaderboard they have played.
